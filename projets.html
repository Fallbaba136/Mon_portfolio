Allô Tiak-Tiak

Plateforme backend de mise en relation entre clients et livreurs moto indépendants (tiak-tiak), ciblant le marché africain. Le système gère l'authentification JWT, les profils riders/clients, et un cycle de vie complet des commandes.

Statuts de commande : pending → accepted → in_progress → delivered → confirmed avec gestion des litiges et horodatage complet pour traçabilité. Base de données PostgreSQL en production, SQLite en développement.

FastAPI Python PostgreSQL SQLAlchemy 2.0 Alembic JWT Auth Pydantic v2 REST API
Fonctionnalités clés
  • ✓ Authentification JWT (riders & clients)
  • ✓ Gestion des profils utilisateurs
  • ✓ Cycle de vie complet des commandes
  • ✓ Système de litiges et disputes
  • ✓ Migrations de base de données (Alembic)
  • ✓ Tests end-to-end via HTTPie
